# PWC calendar booking page

Responsive static booking page for Dr Daniel Moses and Property Wealth Corporation.

Serve this repository root with any static web server, or open `index.html` in a browser. All images are local in `assets/`.

Both booking buttons use the existing GoHighLevel calendar. Calendar fees, hours, and administrative settings are not configured by this project.

This repository upload does not deploy the page, enable GitHub Pages, or change the existing live domain.
